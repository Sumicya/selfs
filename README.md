# Sumicya 规范

以**辩证法、简单性、先进性、自由性**指导项目工作。默认分支的 [GLOBAL.md](GLOBAL.md) 是唯一对外规范入口，[CHANGELOG.md](CHANGELOG.md) 按日期记录变更。本仓文档不带版本号。

## 使用

开始任务先读项目 `AGENTS.md` 和最新规范，再核对相关实现。有实际冲突就提问，已明确要求直接执行；事实、推断和未验证事项分开说明。

```text
读 Sumicya/selfs 默认分支的 GLOBAL.md 和当前项目 AGENTS.md；本轮任务：……
```

项目 `AGENTS.md` 只保留项目事实、必要限制和规范指针，不复制全局规则，不写版本号或同步戳。发现本仓条目与规范冲突，当轮改本仓条目并报主人。无法读取远端时如实说明，不假称已读最新。

## 修改

修改规范时清除相反表述，更新变更记录和本仓 `AGENTS.md`，核对相关文档一致性。本轮改动提交并推送到会话分支，收尾不留未提交或未推送的改动；尚未合入默认分支的内容是待审版本，不代表全局生效，合并与发布按明确授权执行。

历史记录不作为现行规则例外。本仓不维护各项目的实时状态表，也不设置规范检查 CI；核对由 agent 在会话中完成。
